# 노리 공모사업 알림봇 — 설치 안내서

대구 복지 게시판을 자동으로 살펴보고, **기능보강·환경개선·지원사업** 같은 키워드가 들어간
새 공고가 뜨면 메신저로 즉시 알려주는 봇입니다. 별도 서버 비용 없이 GitHub에서 자동으로 돕니다.

---

## 무엇이 들어 있나

| 파일 | 역할 |
|------|------|
| `welfare_alert.py` | 실제로 게시판을 확인하고 알림을 보내는 본체 |
| `.github/workflows/welfare-alert.yml` | 평일 오전 9시·오후 2시(한국시간)에 자동 실행하는 설정 |
| `requirements.txt` | 봇이 쓰는 부품 목록 (자동 설치됨) |
| `state.json` | (실행되면 자동 생성) 이미 알린 글을 기억해 중복 알림을 막는 기록 |

---

## 설치 순서 (코드를 직접 손볼 필요 없습니다)

### 1. GitHub 저장소 만들기
GitHub에서 새 저장소(repository)를 하나 만들고, 위 3개 파일을 그대로 올립니다.
(`.github/workflows/` 폴더 구조는 유지해야 합니다.)

### 2. 알림 채널 주소 등록하기
저장소의 **Settings → Secrets and variables → Actions → New repository secret** 으로 들어가
아래 값을 등록합니다.

- 이름: `WEBHOOK_URL`
- 값: 알림을 받을 메신저의 Webhook 주소

> **가장 빠른 테스트 방법**: 슬랙·디스코드·팀즈 중 하나의 Webhook 주소를 넣으면
> 5분 안에 동작을 눈으로 확인할 수 있습니다. 네이버웍스 연동은 아래 4번 참고.
>
> 봇이 주소를 보고 메신저 종류(슬랙/디스코드/팀즈/텔레그램)를 알아서 판별해 형식을 맞춰 보냅니다.
> **텔레그램만 예외**: 텔레그램은 보낼 대화방 번호가 따로 필요해서, `WEBHOOK_URL` 에
> 봇 발송 주소(`https://api.telegram.org/bot<토큰>/sendMessage`)를 넣고, 추가로
> `TELEGRAM_CHAT_ID` 시크릿에 대화방 번호를 등록하면 됩니다.
>
> **발송이 일시적으로 실패하면** 잠깐 기다렸다가 자동으로 다시 시도하고, 그래도 실패한 공고는
> '아직 못 보낸 것'으로 남겨 두었다가 다음 실행(평일 9시·14시) 때 다시 보냅니다 — 공고를 놓치지 않습니다.

### 3. 첫 실행으로 '기준선' 잡기
저장소의 **Actions 탭 → '노리 공모사업 알림봇' → Run workflow(수동 실행)** 를 누릅니다.
- **최초 1회는 알림을 보내지 않습니다.** 지금 올라와 있는 기존 글들을 '이미 본 글'로 기록만 합니다.
- 이렇게 해야 다음부터 **진짜 새 공고만** 알림이 옵니다. (첫날 옛 글 폭탄 방지)

이후에는 평일 오전 9시·오후 2시에 알아서 돌아갑니다.

---

## 4. 네이버웍스로 받고 싶을 때

기본은 위의 `WEBHOOK_URL`로 발송합니다. 네이버웍스 봇으로 받으시려면 아래 6개 값이 필요합니다.
이 값들만 알려주시면 코드는 그대로 두고 바로 연결해 드리겠습니다.

`NW_BOT_ID`, `NW_CHANNEL_ID`, `NW_CLIENT_ID`, `NW_CLIENT_SECRET`,
`NW_SERVICE_ACCOUNT`, `NW_PRIVATE_KEY`

(6개가 모두 등록되면 봇이 자동으로 네이버웍스로 보냅니다. 일부라도 비어 있으면 `WEBHOOK_URL`을 씁니다.)

## 조정하고 싶을 때 (말씀만 주세요)

- **키워드 추가/삭제**: 현재 `기능보강, 환경개선, 공모사업, 지원사업, 물품지원, 개보수, 리모델링, 기자재, 가전, 후원물품`
- **실행 시간 변경**: 현재 평일 9시·14시
- **감시 게시판 추가**: 예) 복지넷(bokji.net) 사업공모, 사랑의열매 대구공동모금회 등
  → 소스를 끼워넣는 구조라 추가가 간단합니다.

## 참고 — 어떻게 동작하나 (기술 메모)

- 대상 사이트는 화면을 자바스크립트로 그리는 SPA지만, 내부적으로 `api.welfare.net`의
  JSON 데이터를 받아옵니다. 그래서 무거운 브라우저 자동화 없이 그 JSON을 직접 받아옵니다.
  (빠르고, 잘 안 깨지고, GitHub Actions에서 브라우저 설치가 필요 없습니다.)
- 사용 API: `GET https://api.welfare.net/daegu/na/ntt/selectNttList.do` (인증 불필요, 검증 완료)
- 같은 계열의 다른 게시판은 `mi`(메뉴 번호)·`bbsId`(게시판 번호)만 바꾸면 그대로 동작합니다.
